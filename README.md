# Design Patterns Repository

Welcome to the **Design Patterns Repository**! This repository provides practical examples of software design patterns categorized into three main types:

## Repository Structure

The repository is organized into three folders:

1. **Creational Patterns**

    - Focus on object creation mechanisms to ensure flexibility and reuse of existing code.
    - Examples include:
        - Singleton
        - Factory Method
        - Abstract Factory
        - Builder
        - Immutable

2. **Structural Patterns**

    - Deal with object composition to ensure proper structure and relationships between entities.
    - Examples include:
        - Adapter
        - Composite
        - Proxy
        - Bridge
        - Decorator
        - Facade
        - Flyweight

3. **Behavioral Patterns**
    - Concerned with algorithms and communication between objects.
    - Examples include:
        - Strategy
        - Observer
        - Command
        - State
        - Chain of Responsibility
        - Mediator
        - Memento
        - Iterator
        - Template
        - Visitor

## Design Patterns

The code is written in TypeScript and uses Deno to execute. You can also use Bun or Node if you prefer.

If you use Node, you will need to configure TypeScript, so Deno or Bun is recommended for simplicity.

## Purpose

Learn more about:

-   Understand the fundamental concepts of design patterns.
-   Learn how to implement these patterns with real-world examples.
-   Improve code readability, reusability, and maintainability.
